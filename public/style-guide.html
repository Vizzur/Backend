📋 Guía de Estilos - Servidor Backend

Esta es una página estática servida desde /public

Contenidos de esta Guía

1. Estructura de Rutas

El servidor implementa las siguientes rutas:

  • GET / - Vista dinámica con EJS (HTML)
  • GET /status - Información del servidor (JSON)
  • GET /style-guide.html - Este archivo estático (HTML)

2. Middleware Configurado

app.use(express.static(path.join(__dirname, 'public'))); app.use(express.json()); app.use(express.urlencoded({ extended: true }));

3. Motor de Plantillas

Se utiliza EJS (Embedded JavaScript) para renderizar vistas dinámicas. Las plantillas se encuentran en la carpeta views/.

4. Archivos Estáticos

Los archivos estáticos (CSS, JS, imágenes) se sirven desde la carpeta public/.
